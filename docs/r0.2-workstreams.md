## Current release boundary

The production system can queue and execute an immutable GPU container, safely cancel queued and
active work, recover expired leases with a bounded retry, stage an immutable curated dataset
read-only, and record the run's exact inputs, actual execution interval, MLflow metrics and durable
verified outputs. The complete dataset-to-MLflow path passed live acceptance on 2026-09-28.

Two things stand between here and a complete R0.2:

1. **The witnessed network-loss exercise.** Everything it needs exists — the soak workload, the
   runbook and the digests it pins. It needs a human to disconnect a machine.
2. **A useful model objective.** A real LeRobot dataset and curated view now prove the full
   mechanism, including lineage and a verified checkpoint. The bounded linear smoke model proves
   reproducibility rather than a useful robotics outcome, so the first useful model objective and
   its authorised data remain a product choice.

Neither is blocked on engineering. Both are user-owned, which is worth stating plainly rather than
leaving them to look like work in progress.
